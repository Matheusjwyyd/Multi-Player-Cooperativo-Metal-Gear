# Multi Player Cooperativo Metal Gear

Projeto Phantom Brothers para pesquisar e desenvolver multiplayer cooperativo de campanha no METAL GEAR SOLID V: THE PHANTOM PAIN.

## Estado

O projeto contém a auditoria da instalação do jogo, pesquisa do caminho de sessão FOX/FOB e um protótipo independente de servidor. Ainda não há uma build carregável dentro do jogo.

Veja [`PHANTOM_BROTHERS/README.md`](./PHANTOM_BROTHERS/README.md) para o estado e a documentação técnica.

## Arquivos do jogo

`MGS_TPP/` é uma instalação local do jogo e fica fora do Git. Não distribua executáveis, bibliotecas ou dados proprietários do MGSV neste repositório.
